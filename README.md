# Aura Estetik ve Güzellik Merkezi

Next.js App Router, TypeScript, Tailwind CSS, Framer Motion ve Lucide React ile hazırlanmış premium kurumsal web sitesi.

## Kurulum

```bash
pnpm install
pnpm dev
```

Site lokal olarak şurada açılır:

```text
http://localhost:3000
```

## Yayın

Vercel'e yüklerken Environment Variables bölümüne gerçek alan adınızı ekleyin:

```text
NEXT_PUBLIC_SITE_URL=https://www.alanadiniz.com
```

Detaylı yayın adımları için:

```text
README_DEPLOY.md
```
